# Trazo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** app local para letra personal, páginas imprimibles y reproducción automática de imágenes.
**Architecture:** núcleo de imágenes/fuentes, almacenamiento y cola SQLite con trabajador local, servidor HTTP limitado a loopback, interfaz estática.
**Tech Stack:** Python 3.12, Pillow, NumPy, OpenCV, fontTools, ReportLab; HTML/CSS/JS.
**Spec:** ../../ui/brief.md

## Global Constraints
- Archivos del usuario locales. Sin cuentas ni llamadas a servicios externos.
- No prometer reconstrucción idéntica de una fuente ni de un dibujo vectorizado.
- No requiere intervención del usuario durante la implementación; decisiones reversibles.
- No hay repositorio Git preexistente. Se entrega código y pruebas en esta carpeta aislada.

## Review Focus
- Foto girada o con perspectiva: corregir por marcas o rechazar con explicación.
- Muestras vacías y letras sin muestra: no generar una fuente o PDF engañoso.
- Transparencia, agujeros de letras y EXIF: conservar la forma real.
- Cierre del navegador/reinicio del servidor: trabajos conservados en SQLite.
- Archivos grandes, nombres/rutas manipulados y solicitudes de otro origen: rechazar.
